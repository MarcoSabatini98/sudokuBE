# Fonte wordlist italiana

`wordlist-it.json` deriva dall'elenco **1000 parole italiane comuni** del progetto
[napolux/paroleitaliane](https://github.com/napolux/paroleitaliane).

Elaborazione applicata: minuscole → rimozione accenti → solo lettere A-Z →
lunghezze 3-12 → deduplica → MAIUSCOLO.
